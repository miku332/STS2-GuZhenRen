# STS2-GuZhenRen

`STS2-GuZhenRen` 是一个以《蛊真人》为主题的《杀戮尖塔2》同人角色模组。玩家将扮演古月方源，以蛊虫组成牌组，在爬塔过程中经营空窍、选择本命蛊、积累道痕、渡过灾劫，并逐步升炼至更高转数。

本项目以《杀戮尖塔1》的 `Slay the Spire Mod - Reverend Insanity（蛊真人）` 为主要还原标准，并参考其他《杀戮尖塔2》移植项目，对原有卡牌、遗物、事件和角色机制进行适配。

## 模组特色

- **方源角色**：拥有独立的初始牌组、卡池、遗物池、药水池和角色资源。
- **空窍与升转**：从一转空窍逐步成长至十转仙窍，不同转数会影响卡牌和机制效果。
- **本命蛊**：开局选择自己的本命蛊，并随角色转数提升而升炼。
- **灾劫系统**：成长过程中需要面对天劫、地灾、浩劫、万劫和混沌大难等考验。
- **多种流派**：包含力道、剑道、血道、智道、炎道、光道、土道、运道、宙道等蛊虫与联动机制。
- **道痕系统**：不同流派可以积累对应道痕，强化相关卡牌和战斗效果。
- **杀招与蛊方**：获得蛊方后，可以在篝火处消耗指定材料合炼杀招。
- **特殊卡牌**：包含本命蛊、杀招、仙元、仙蛊屋、虚影和其他不会进入普通奖励池的特殊内容。
- **遗物与事件**：移植了多种蛊虫遗物、空窍遗物、杀招蛊方以及白骨传承、赌石场、盗天真传、逆流河等事件。
- **原作机制还原**：包括念、情、焚烧、剑锋、剑痕、转运、概率、积土、冷血等特色机制。

## 当前状态

模组目前仍在开发和测试中。主要角色框架、卡牌体系、空窍升转、本命蛊、灾劫、杀招合炼、部分事件与遗物已经可以体验，但仍可能存在尚未移植的内容、数值偏差、兼容问题或特殊场景错误。

本项目优先还原《杀戮尖塔1》蛊真人模组的玩法；当一代机制无法直接适配《杀戮尖塔2》时，会根据塔2的规则进行必要调整。

> **注意：本 mod 使用 ai 进行开发，可能会存在错误。**

遇到卡牌无法打出、战斗流程卡住、文本显示异常或效果与描述不符时，欢迎提供复现步骤、截图和游戏日志。
